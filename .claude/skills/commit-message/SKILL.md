---
name: commit-message
description: When writing commit messages, look at the current changes and use below instructions to write a good commit message.
---

When writing a commit message, always include:

1. Use the `git diff` command to see the changes you have made before writing the commit message.
2. The first line in the commit message should be a short summary of the changes.
3. Instead of explaining the changes in the commit message, say why you made the changes.
4. After the first line, use `-` and write rest of the commit message.
